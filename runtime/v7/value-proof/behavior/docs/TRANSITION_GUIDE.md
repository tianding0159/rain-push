# Expression-Transition Guide (function → surface)

The distinctive claim about 糖糖 is that a stable underlying **function/need** surfaces as a
*contradictory* expression. This guide annotates those `source_state → surface_replacement`
transitions — as candidates, gated by concurrency class, never pre-written as conclusions.

## Candidate transitions (from `behavior-vocab.json → expressionTransitions`)

`vulnerability→irritation` · `attachment_need→accusation` · `shame→bold_escalation` ·
`fear_of_rejection→control` · `affection→teasing_attack` · `reassurance_request→command` ·
`sadness→exaggerated_spectacle` · `desire→challenge` · `jealousy→exclusivity_demand` ·
`overload→absurd_humor` · `public_confidence→private_crash` · `self_exposure→immediate_masking`.

These are **candidates only**. The corpus decides which hold, for whom, and how strongly.

## What to record per transition (§5)

- **source state candidate** — the underlying function/affect (with alternatives).
- **surface replacement** — the observable expression (an L1 behavior atom / affect).
- **observable evidence** — what on the page supports the *surface* (always present).
- **interaction function** — the L2 function the transition serves.
- **concurrencyClass** — `A_explicit` / `B_context_strong` / `C_designed_inference` /
  `D_undecidable`. Only A/B count as evidence for a pattern; C is a hypothesis.
- **supporting / counterexample hashes**, **confidence**, **evidence grade**.

## Multi-emotion / contradiction (§6)

Do not compress a line to one emotion. Use the four affect roles:

- `primary` (surface), `opposing` (co-present contrary affect), `masked` (hidden), `leak`
  (unintended tell).

Look specifically for co-presence such as high-energy+low, cheerful+dark, shy+bold,
attack+overture, possessive+fear-of-loss, confident-performance+self-loathing,
push-away+pursue, want-control+want-them-to-stay-freely. Then classify concurrency A/B/C/D. The
source-state half of a transition is usually inferred; the surface half must always be
observable. If only the surface is evidenced, grade it E1 and leave the source as a low-
confidence candidate.

## The trap this guide guards against

It is tempting to read every contradiction as proof of the exact transition we hoped to find.
The concurrency-class gate (C excluded from statistics) plus the counterexample requirement are
what keep an inferred `shame→bold_escalation` from being counted as if the text stated it. A
transition becomes an E3 pattern only when multiple records, multiple wordings, and multiple
surface tones support it and it survives a second round.
